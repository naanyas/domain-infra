How the learning loop works:
  • Every verdict confirm/correct, entity tag, cluster mark, and threat flag writes a TrainingLabel row with a frozen snapshot of all signals at that moment.
  • The snapshot includes: SDAT raw scan, IPQS enrichment, entity tags + reputations, fingerprint hashes + scores, all ~50 feature columns.
  • Re-train by running the management command. It fits a gradient-boosted classifier and persists it to ml_models/.
  • The scoring pipeline auto-loads the latest model on each submission. Predicted p(fraud) moves the score by up to ±30 points.
  • Predictions are logged on every verdict's reasons list so you can see what the model thought and why.
